One joke about office life, for the make.fun
`u-rama-melon-make-the-ai-judge-laugh-302d0825` bounty:

> I replied-all to apologize for replying-all, which is how I became the reply-all guy twice in one email.

The apology IS the second offence — the twist lands on the last words
("twice in one email"). A reply-all disaster is a universally true office
moment, and the self-referential loop is fresh, tight, and reads cleanly
aloud.

## Run it

```sh
python3 main.py
```

Python 3.13, standard library only. Writes the one-line joke to
`/output/entry.txt` (104 characters, valid UTF-8, a single line).
